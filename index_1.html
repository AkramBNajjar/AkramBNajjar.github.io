Automated RF gasket cutting machine

Applied Materials

RF gaskets were being cut to length by hand against a tape measure — slow, and the tolerance depended on who was doing it. I built a machine that feeds stock to a set length and tells the operator exactly when to cut.

  • Operator picks a product on the touchscreen; the machine feeds stock while rotary encoders track real fed length, then stops at target and signals ready to cut.
  • Wrote the motion firmware in Arduino C++ on a Mega with a terminal shield driving a NEMA 23 stepper.
  • Built the operator interface in Python and Tkinter on a Raspberry Pi 5, laid out for a 5″ 1024×600 panel.
  • Specified and wired the control panel end to end: stepper driver, DC supplies, terminal blocks.

O-ring cleaning station

Applied Materials

A benchtop station that washes and dries O-rings on a repeatable cycle instead of by hand — built on industrial components so it could live on the floor and be serviced by the people using it.

  • Programmed the wash-and-dry cycle on an Arduino-based PLC in C++, driving stepper motion through each stage.
  • Laid out the enclosure on DIN rail so every component is standard, labeled, and swappable.
  • Plumbed deionized water through an inline filter for the wash stage.
  • Dried with a DI air knife to avoid residue and static pickup on the seal surface.
